# Validation Report

## Overall assessment: Share with caveats

该结果可用于当前项目的内部回归与注明“离线评测”的简历表述；分类样本量较小、评分为冻结事实字符串命中，因此不应外推为普适模型结论。

## 数据与粒度

- 粒度：一行对应 case × mode × repeat。
- 完整性：96 行，96 个唯一运行键，失败/未完成 0 行。
- 分层：4 类 × 每类 4 题 × 3 模式 × 2 轮；每个 category/mode 单元均为 8 行。
- 正式数据只保留退出 0、完成事件存在、答案非空、token 非零的运行。

## 独立计算抽查

- Multi-hop strict accuracy：Wiki 62.50% - RAG 37.50% = +25.00 pp。
- Multi-hop completeness：Wiki 94.09% - RAG 83.75% = +10.34 pp。
- 汇总与原始 96 行重新计算一致。

## 风险与解释

1. **中等：小样本。** 每分类/模式只有 8 次运行；bootstrap 区间必须与点估计一起报告。
2. **中等：字符串评分保守。** 语义正确但未采用冻结变体的答案可能被判漏；Strict accuracy 不等同于人工语义正确率。
3. **中等：题集偏向 Wiki 强项。** 语料与题目专门覆盖层级、跨文档、多跳和全局综合；不得表述成开放域总体提升。
4. **低：环境抖动。** 正式运行前/中途出现 DNS/EOF，失败行已隔离并重跑；最终数据无失败行，但端到端延迟仍包含网络波动。
5. **高：Hybrid 工具链。** M02 两轮出现无效文档别名并触发工具错误，导致 token 长尾；在修复前不宜把 Hybrid 描述为稳定的默认最优路径。

## 结论边界

- Multi-hop 的 Wiki 完整度优势区间不跨 0，可以写为本冻结题集上的离线结果。
- Overall 与 Global 的差异区间跨 0，不写“全面领先”或“全局显著提升”。
- Global strict 0% 表示每次至少漏一个冻结事实组，而非答案全错。
