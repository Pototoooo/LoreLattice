# LoreLattice 简历表述候选

## 推荐版本（技术/后端）

- 为 LoreLattice RAG/Agent 平台搭建可复现评测流水线：基于 12 份合成企业制度文档
  构造 60 个独立事实、120 条双问法测试集，覆盖单/多文档检索、回答引用、Agent
  工具链、回归与 k6 压测，并保留原始 JSONL、环境快照和决策日志。
- 对 Hybrid、Vector、Keyword 三条检索路径完成 360 次消融实验；在 Top-8 下取得
  Hybrid Hit@8 99.17%、MRR@8 93.13%，并识别精确术语集对 Keyword 的偏置，
  据此提出按查询类型路由、暂缓无收益 rerank 成本的优化方向。
- 对 120 条 KnowledgeQA 结果逐答审定，受控运行下完全通过率 98.33%、相关引用率
  100%；同时通过 4 并发探针发现 45.83% 请求在突发阶段退化为固定拒答/EOF，定位
  质量分数与并发稳定性必须分开验收。
- 验证 Agent 重复回答修复：同一事实题连续运行 20 次均返回正确事实且最终段落无
  重复，5 个知识库外问题均正确拒答；进一步发现 1 次 128.6 秒长尾及 2 个未投影
  tool_result，形成服务端总超时与事件完整性改进项。
- 在 Apple M1 Pro 本机 Docker 环境对已鉴权只读 API 执行 10/100/300 target RPS
  阶梯压测，完成 6,134 次 HTTP 200，P95 6.42 ms；结合容器资源采样定位无节流
  压测下 Nginx→App 临时端口耗尽的 502 边界。

## 推荐版本（产品/AI 平台）

- 设计 LoreLattice RAG 质量验收框架，将“检索命中、回答正确、引用可信、Agent
  稳定、系统性能”拆成独立指标，避免用单一准确率掩盖并发失败与上游限流。
- 构建 60 个独立企业事实/120 条问法的离线基准，验证 Hybrid Top-8 命中率
  99.17%、受控回答完全通过率 98.33%、相关引用率 100%，并明确合成数据与
  Codex 审定不等同于真实用户价值或专家盲测。
- 通过失败样本复盘识别三项可落地优化：精确术语查询优先 Keyword、KnowledgeQA
  增加排队/退避与并发门控、Agent 服务端落实 90 秒总截止时间。

## 面试时必须主动说明

- 120 条 query 来自 60 个事实的两种问法，不是 120 个独立事实。
- 文档为合成企业资料；没有真实客户留存、采纳率或业务收入结论。
- 98.33% 是 Codex 对冻结预期答案的逐条审定，不是独立领域专家双盲评审。
- 300 RPS 测的是本机只读列表 API，不是调用大模型的问答吞吐。
- 并发 4 的 KnowledgeQA 有明显退化，不能只展示重试后的质量成绩。
